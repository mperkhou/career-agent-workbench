# Career Agent Workbench 1.2.0

Status: workflow initialized; implementation has not begun.

This in-progress release is scoped to the nine approved operational-parity
gaps deferred from 1.1.0. Work is divided into three bounded implementation
and reassessment pairs: workflow execution and variant-review evidence;
tracker information density and structured resume editing; and a practical
cover-letter workbench with compact professional pagination.

The committed workflow plan preserves the modular public architecture and the
existing state, rendering, selection, and human-review foundations. It does
not authorize restoration of the legacy Flask monolith, provider expansion,
authenticated LinkedIn access, application submission, generalized security
or deployment work, or unrelated feature development.

Validation will use synthetic fixtures and disposable copies derived from the
private ops-dev workspace. Full retained ops is reserved for bounded,
content-free aggregate compatibility checks. Private dotenvs, databases,
profile data, identifiers, generated artifacts, and raw evidence remain
outside Git.

The legacy application remains the operational fallback. Push, pull-request
creation or mutation, merge, tag, release, cutover, and legacy retirement each
remain separately gated and require explicit user authority.
