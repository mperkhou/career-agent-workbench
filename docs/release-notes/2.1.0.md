# Career Agent Workbench 2.1.0

Status: the documentation-parity workflow is initialized; private-source
anonymization and all public documentation implementation remain staged behind
the committed P/G plan and explicit pre-P01 approval.

This documentation-centered release will replace the intentionally compact
fictional resume text and Master Resume Object with a realistic, full-depth
public demo. The demo will preserve the source profile's technical breadth and
section depth while replacing identifying people, employers, locations,
institutions, projects, credentials, links, chronology, and distinctive
phrasing. One designated long-form role will be reduced to roughly half its
source volume; the remaining roles will preserve their full substantive depth.

After separate review of the public resume text and its derived MRO, the README
will be rebuilt to relative parity with the mature archived documentation. Its
examples will come only from the approved fictional demo, and its diagrams and
Flask screenshots will be recreated or retained only after accuracy and
privacy review.

Private source content, application state, generated career artifacts,
credentials, machine-specific paths, and content-bearing evidence remain
outside Git. Product behavior changes, provider calls, authenticated browsing,
job-posting retrieval, push, PR, merge, tag, and publication are outside the
initialized work unless separately approved.
