# Career Agent Workbench 2.0.0

Status: the archive-first Flask replacement workflow is initialized, and its
first product slice preserves the exact archived Flask module as an inactive
packaged source baseline. Activation remains staged behind the committed P/G
plan.

This major release replaces the reconstructed 1.1/1.2 Flask user interface
with the mature application from the archived LinkedIn Career MCP codebase.
The archived application is the behavioral, route, and visual source of truth.
Public-workspace configuration, database compatibility, packaging, and safety
are adapted around that source rather than used as a basis for redesigning it.

The initial source is one tracked, clean Python module containing the Flask
routes and inline HTML, CSS, and JavaScript. It is bound to an exact repository
commit, tree, Git blob, and SHA-256 in the committed workflow plan. The first
implementation slice copies that source exactly before any activation or
compatibility change.

That exact source is now stored as
`career_agent_workbench._archived_flask_source`. It is deliberately not
imported by the package or wired to the console/operator entrypoint yet. A
focused test binds its SHA-256 and line count, while the existing reconstructed
application remains active until the public runtime adapter is implemented and
validated in the next phase. Ruff lint still covers the imported source, while
Ruff formatting excludes that one file so the bound bytes cannot be changed by
an automatic format pass.

Private profile files, application rows, databases, credentials, generated
career artifacts, machine-specific paths, and private environment values are
not migration inputs and must remain outside Git. Validation uses fictional
workspaces and disposable database copies. Provider calls, authenticated
LinkedIn access, application submission, publication, cutover, and retirement
of the archived fallback remain separately gated.
