# Changelog

## [1.0.0] - 2026-08-01

### Added

- Added provider-neutral public job models, guest-only LinkedIn public search
  and detail parsing, bounded generic posting parsing, query planning, matching,
  filtering, and atomic application/JOD seeding.
- Added a centrally resolved runtime configuration with deterministic dotenv
  discovery, immutable settings and workspace paths, explicit-over-process-
  over-dotenv precedence, compatibility aliases, and content-hidden errors.
- Added caller-injected résumé objects, packaged autoescaped rendering,
  structural PDF validation, deterministic ATS diagnostics, and optional
  isolated offline browser rendering with a ReportLab fallback.
- Added explicit SQLite application state for JOD, ARO, CLO, artifacts, ATS
  summaries, lifecycle fields, and isolated `v1`, `v2`, and `manual` résumé
  variants with reversible selection.
- Added evidence-grounded refinement, manual-pass, and highlighting workflows
  with exact canonical-file digests, immediate current-file rechecks,
  conditional writes, failure atomicity, and raw model-traffic
  non-persistence.
- Added renamed CLI commands, bounded operational scripts, and path-free Make
  defaults that resolve state centrally after parsing while preserving explicit
  overrides and batch selection.
- Added a small local Flask tracker/action adapter and a proportional FastMCP
  stdio server with three workspace-independent public job tools and one lazy
  configured matching tool.
- Added a from-scratch fictional offline demo, representative behavior
  coverage, synthetic integration tests, public-safety tree/distribution
  checks, and minimal read-only CI with isolated installed-package smoke.
- Added a fresh public README, two approved architecture diagrams, and nine
  annotated public-safe workflow illustrations grounded in the fictional demo.

### Safety and governance

- Keeps real profile data, tracker state, generated documents, credentials, and
  model configuration in an operator-owned private workspace selected through
  one ignored `.env` root.
- Limits LinkedIn integration to guest-accessible public data: no
  authentication, private-member access, application submission, or employer
  contact.
- Preserves human-review checkpoints, evidence grounding, variant isolation,
  explicit selection, bounded parsing/network/process behavior, stable
  content-free failures, and atomic state updates.
- Treats the included UI images as synthetic documentation illustrations, not
  claims of additional public Flask routes or a live application capture.

### Validation

- Uses fictional reserved-domain fixtures and temporary workspaces throughout
  tests and demo flows.
- Aligns version `1.0.0`, this changelog, the release note, README package
  metadata, and explicit source-distribution membership.
- Requires clean-history candidate validation, private-remote review, and
  signed-out verification before publication.
